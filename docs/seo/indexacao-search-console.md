# Pedidos de indexação no Search Console

Registro das páginas novas ou atualizadas que o Montinho manda para o
Google pela Inspeção de URL ("Solicitar indexação"). O Search Console
aceita um número limitado de pedidos por dia; o que não couber fica para
o dia seguinte.

Como acompanhar cada lote:

1. **No dia:** colar a URL na Inspeção de URL e clicar em "Solicitar indexação".
2. **Em ~7 dias:** conferir se a página aparece como "A URL está no Google".
3. **Em 28 dias:** comparar impressões, cliques e posição da página
   (regra de medição do AGENTS.md).

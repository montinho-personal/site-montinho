# SEO local: o Montinho no Google Maps

Levantamento mensal pelo SerpApi (regra no CLAUDE.md, "Estratégias de SEO com o SerpApi").
Perfil: **Montinho Personal Trainer**, área de cobertura (sem endereço exibido), categoria
"Personal trainer", site ligado.

## Como medir

Cinco buscas no Google Maps, centro em Alphaville (`@-23.4969,-46.8490,13z`), pt-BR:

1. `personal trainer alphaville`
2. `personal trainer tamboré`
3. `personal trainer barueri`
4. `personal trainer santana de parnaíba`
5. `personal trainer a domicílio alphaville`

De cada uma: a posição do perfil entre os 20 primeiros e os 3 primeiros, com o número de
avaliações. É o retrato de um ponto do mapa, sem personalização; quem pesquisa de outro
lugar vê outra ordem. O JSON de cada mês fica nesta pasta.
